# Benjiro — Project Workspace

This repository is the persistent workspace for the **Benjiro Vydiaronpa** creative roleplay project.

## A. Asset Management
Store and organize approved character artwork, reference images, evidence materials, lore, and source documents. Catalog additions in [assets/INDEX.md](assets/INDEX.md), with paths, descriptions, provenance, and status.

## B. Goals, Plans, Status, and Lessons Learned
Maintain living project documentation:
- [Goals](planning/GOALS.md) — intended outcomes and priorities.
- [Plan](planning/PLAN.md) — milestones and upcoming work.
- [Status](planning/STATUS.md) — progress, current blockers, and next actions.
- [Decisions](docs/DECISIONS.md) — key choices and their reasoning.
- [Lessons Learned](docs/LESSONS_LEARNED.md) — insights and practices for future work.

Distinguish confirmed RP canon from theories, interpretations, and proposed retcons.

## C. Handoffs for Next Agents
- [AGENTS.md](AGENTS.md) contains standing instructions for assistants working on this project.
- [HANDOFF.md](HANDOFF.md) contains the most recent session handoff.

**Before starting project work in any new chat:** Read `AGENTS.md`, then `HANDOFF.md`, followed by `planning/STATUS.md` and relevant source files. The current user's instructions and corrections take priority over outdated notes.

**At the end of each substantive session:** Update status and the handoff with work completed, verified facts, open questions, and exact next steps; update decisions, lessons, and asset listings as appropriate.

> Repository documentation cannot automatically make an agent in another chat read it. Give the future agent access to this repo and instruct it to follow `AGENTS.md`.

## Safety and Accuracy
This repository is **public**. Do not commit private correspondence, credentials, sensitive personal information, or materials lacking appropriate sharing rights. Confirm chapter evidence from primary sources rather than inventing missing details. Document corrections and retcons explicitly.
