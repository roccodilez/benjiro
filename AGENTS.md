# Instructions for Future Agents

## Mandatory Start-of-Session Procedure
1. Read this file (`AGENTS.md`) before doing project work.
2. Read `HANDOFF.md` completely to understand the current task and most recent session.
3. Read `planning/STATUS.md`, then `planning/GOALS.md` and `planning/PLAN.md`.
4. Consult relevant assets, source material, and decision logs before analysis or drafting.
5. Resolve contradictions with the user's latest explicit instructions; record corrections.

These are standing project instructions for assistants with access to this repository. They do not automatically execute in unrelated chats; the user or agent environment must direct the next agent here.

## A. Asset Management
Place approved artwork, references, documents, and evidence in `assets/`. Update `assets/INDEX.md` with location, purpose, source, and status. Do not treat an uncited recollection as project canon.

## B. Goals, Plans, Status, Lessons
Update `planning/GOALS.md`, `planning/PLAN.md`, `planning/STATUS.md`, `docs/DECISIONS.md`, and `docs/LESSONS_LEARNED.md` when work meaningfully changes. Keep established facts, inferences, and possibilities separate.

## C. Handoff Rules
Before ending a substantive session, update `HANDOFF.md` and `planning/STATUS.md`. Include:
- date and active thread
- completed changes with links
- verified/locked facts
- competing interpretations labeled as tentative
- unresolved questions and blockers
- immediate next actions
- required source files

## RP-specific Practices
- Preserve established character voices, relationships, timelines, and explicit retcons.
- For trials: assess preparation, activation, fatal mechanism, staging, time windows, motive, means, opportunity, and contrary evidence. Do not treat accusations as proof.
- Make a source distinction between player statements, in-character dialogue, confirmed evidence, and theory.
- Never silently promote an inference into canon.

## Security and Review
This repository is public. Exclude secrets, sensitive personal details, private messages, or files without appropriate sharing rights. Read existing contents before replacing any file. Report actual changes accurately.
