# Lessons Learned

**Updated:** 2026-11-11

## Preserve Evidence Boundaries
Do not invent missing case evidence or character canon. Explicitly distinguish confirmed information, inferences, and hypotheses.

## Record Retcons
Current user corrections supersede older interpretations. Update affected notes and flag changes rather than quietly preserving outdated details.

## Keep Handoffs Actionable
A useful handoff gives the active task, actual completed work, unresolved dependencies, relevant file paths, and precise next steps.

## Protect Public Repository Content
Avoid confidential personal details, credentials, private correspondence, and unapproved third-party content.
